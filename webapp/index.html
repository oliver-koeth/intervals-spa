Settings

Data privacy

ℹ This app stores settings and optional intervals cache in your browser Local Storage. This implementation has no built-in analytics, tracking pixels, or telemetry. Data is sent only when you trigger API actions, and only to intervals.icu, Strava, and optionally your own local proxy endpoint (/api/*) when using Proxy mode. On page load, the chart library is also fetched from jsDelivr CDN. Use Reset all settings to remove stored values from this browser.

Note: this is a technical transparency summary, not a complete GDPR privacy notice.

Intervals.icu Connection

⚠ Enter your Athlete ID and API key to enable search. Find your athlete ID at the bottom of intervals.icu/settings and generate an API key under Account → API access.

Strava Connection

Stored locally in this browser only.

⚠ Enter your Strava Client ID and Client Secret, then connect OAuth to retrieve an access token with read + activity:read_all scope for segment search and HR streams. If Strava shows redirect_uri invalid, set OAuth Redirect URI to exactly the callback URL configured in your Strava app.

API Mode

ℹ Auto is recommended — it uses the local Python proxy when running on localhost and direct API access on GitHub Pages. Set to Proxy only if you are running server.py locally and want to force it. Set to Direct only for debugging.

Manual

This guide walks through the complete local workflow: configure the external accounts, connect the app, search for activities or intervals, store the results in your browser, and compare selected efforts in the dashboard. The screenshots are thumbnails; click any thumbnail to inspect the full-size image in the built-in viewer.

1. Configuration first

Before using search or comparison, collect the credentials that allow the app to talk to Strava and Intervals.icu. The app stores these values only in your browser's local storage, so setup is per browser and per device. If you switch machines or clear browser storage, you will need to enter the values again.

Strava

Open Strava API settings, click Edit, and set Authorization Callback Domain to oliver-koeth.github.io. This domain must match the hosted app domain because Strava checks it during OAuth. If the domain is different, Strava will reject the connection before the app receives an access token.

After saving the Strava app configuration, note the Client ID, Client Secret, Access Token, and Refresh Token. The refresh token is especially important because it allows the app to request a fresh access token when the short-lived token expires.

Intervals.icu

Open intervals.icu settings, scroll to Developer Settings, and note your Athlete ID and API Key. The Athlete ID identifies which account to query, while the API key authorizes private workout, interval, stream, and sport-settings requests.

If you use the local proxy mode while developing, these values are sent to the local server and then forwarded to Intervals.icu. In direct mode, the browser calls Intervals.icu itself. In both cases, the values remain under your control and are not sent to any analytics service.

2. Enter settings in Intervals SPA

Open Settings in this app and enter the Intervals.icu and Strava values in the corresponding fields. Click Save before testing any connection; the app reads the saved values when it performs searches, stream requests, and token refreshes.

Then use Connect Strava to complete OAuth. If you are running a local copy or a different deployment, check the OAuth Redirect URI carefully. It must match the callback URL that Strava expects for the current app location. A mismatch usually shows up as a Strava authorization error rather than an app-side error.

After the account fields are saved, optionally load the HR zone model from Intervals.icu. The zone model improves chart readability because the dashboard can color HR streams and zone histograms with your real sport-specific thresholds instead of a generic fallback.

3. Search and save results

Use Search Activities when you want to inspect complete workouts in Activity Lab. Use Search Intervals when you already know the interval label or target duration you want to compare. Use Search Strava Segments when the effort is represented as a Strava segment rather than an Intervals.icu workout interval.

Each search first opens a preview table. Review the preview before adding results, especially when using broad date ranges or loose labels. When the preview looks right, click Add all to activities or Add all to intervals. The rows are stored in local browser storage so you can filter and compare them without repeating the same remote search every time.

4. Work with stored intervals

On the Intervals page, use the filters to narrow the stored rows by label, source, activity type, duration, and date range. This page is meant to be the staging area before comparison: reduce the list to a meaningful cohort, then select the intervals that should be plotted together.

Select specific rows when you want a focused comparison. If nothing is selected, the comparison dashboard can still use the currently filtered set, which is useful for quick exploration. For cleaner charts, keep the selected set small enough that each point still represents a distinct workout or effort.

5. Compare in dashboard

The Compare dashboard shows progression, heart-rate behavior, and relationships between effort metrics across the selected interval set. The upper charts are designed for comparison across time; the lower row is designed for inspecting one pinned interval in detail.

Click any point in the top charts to pin that interval. The zone distribution and HR stream then update to the pinned effort, making it easier to explain why two intervals with similar pace or power may have different physiological cost. If stream data is unavailable for a workout, the dashboard falls back to the metadata it has and shows a diagnostic note.

Quick summary

  1. Collect Strava and Intervals.icu credentials before using search.
  2. Save credentials in Settings, connect Strava, and confirm the redirect URI if OAuth fails.
  3. Load HR zones when you want chart bands and histograms to use your real thresholds.
  4. Search, review the preview table, and add only the rows you want to keep locally.
  5. Filter stored intervals, select a comparison cohort, then inspect pinned efforts in the dashboard.
